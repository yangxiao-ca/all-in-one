# 学习架浏览器扩展

Chrome 与 Edge 通用的 Manifest V3 扩展。它只在用户点击工具栏图标时读取当前页面的标题、链接和公开页面元信息，并由用户确认后写入本地学习驾驶舱的探索池。

## 安装

1. 保持学习驾驶舱在本机运行，并确认可以打开 `http://127.0.0.1:47831/`。
2. 在 Chrome 打开 `chrome://extensions`；在 Edge 打开 `edge://extensions`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本目录中的 `extension` 文件夹。
5. 将“学习架 · 收下当前页”固定到浏览器工具栏。

## 使用

1. 在 B 站、YouTube、公众号文章或任意普通网页打开想留下的内容。
2. 点击浏览器工具栏中的“学习架 · 收下当前页”。
3. 检查自动带入的标题、链接和平台；可选写一句想法、选择状态和订阅源。
4. 点击“收进探索池”。

连接器暂时不可用时，扩展会把待发送内容保存在扩展自己的本地队列中，可在下次打开扩展时重试。它不读取浏览历史、微信聊天记录或未主动打开的页面。
